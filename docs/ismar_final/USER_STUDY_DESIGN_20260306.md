# Vid2Spatial — User Study Design
**Date**: 2026-03-06
**Participants**: N=5 (within-subject, counterbalanced order)
**Duration**: ~45 min/participant
**System URL**: `http://localhost:8090`
**Required**: headphones, Chrome/Firefox

---

## Purpose

이 user study는 Vid2Spatial의 두 authoring modality를 평가합니다:

1. **Video + Bbox**: 비디오에서 물체에 bounding box를 그려 자동 추적
2. **3D Sketch**: 3D 구면에 직접 궤적을 그려 즉각 바이노럴 오디오 생성

평가 차원:
- **Efficiency** (NASA-TLX): 인지 부하, 노력, 좌절감
- **Expressiveness**: 의도한 공간 표현을 얼마나 잘 달성했는가
- **Complementarity**: 두 방식을 언제 쓸지 사용자 인식

## Session Flow

```
00:00  소개 + 동의 (3분)
       - 시스템 설명 (읽지 않고 설명만 듣기)
       - 녹화/기록 동의 받기

03:00  데모 시청 (3분)
       - 진행자가 Video, Sketch 각각 1번씩 시연
       - 참여자는 보기만 함

06:00  연습 (5분)
       - Video: car-5 영상으로 자유롭게 bbox 그려보기
       - Sketch: 자유롭게 구면에 그려보기
       - 질문 허용

11:00  [BLOCK 1] — 그룹 배정에 따라 Video 또는 Sketch (15분)

26:00  NASA-TLX 작성 #1 (3분)

29:00  [BLOCK 2] — 나머지 modality (15분)

44:00  NASA-TLX 작성 #2 + 전체 질문지 작성 (10분)

54:00  종료 + 구두 인터뷰 선택 (5분 이하)
```

## Tasks

### VIDEO TASKS (3개)

*Instruction*: "화면에서 표시된 물체에 bounding box를 그려주세요. Render 버튼을 누르고 헤드폰으로 들어보세요. 오디오가 물체의 움직임을 잘 반영하는지 느껴보세요."

| # | 클립 | 물체 | 주요 움직임 | 제한시간 |
|---|------|------|------------|---------|
| V1 | car-10 | 자동차 | 좌→우 이동 (강한 방위각 변화) | 5분 |
| V2 | dog-1 | 개 | 카메라 방향으로 접근 (거리 변화) | 5분 |
| V3 | drone-13 | 드론 | 빠른 움직임 (정밀도 요구) | 5분 |

각 클립마다:
1. 영상 처음 3초 시청
2. Bbox 그리기
3. Pipeline 실행
4. 헤드폰으로 결과 청취 (30초)
5. Likert 1문항 즉시 체크: "오디오가 물체의 움직임과 일치했다" (1–5)

---

### SKETCH TASKS (3개)

*Instruction*: "아래 시나리오를 읽고, 3D 구면에 그 움직임을 직접 그려주세요. 스크롤로 거리를 조절할 수 있습니다. 그린 후 Render를 눌러 들어보세요."

| # | 시나리오 | 기대 궤적 |
|---|----------|----------|
| S1 | "자동차가 당신의 왼쪽에서 오른쪽으로 지나간다" | 수평 sweep, 일정 거리 |
| S2 | "새가 머리 위로 날아올라 멀어진다" | 위쪽 호, 거리 증가(스크롤↑) |
| S3 | "누군가 앞에서 다가오다가 멈추고, 뒤로 돌아간다" | 앞→중→뒤 호, 거리 변화 |

각 시나리오마다:
1. 시나리오 카드 읽기 (30초)
2. 구면에 그리기
3. Render + 청취 (30초)
4. Likert 1문항 즉시 체크: "그린 궤적이 의도한 방향/거리로 들렸다" (1–5)
5. 불만족 시 Clear + 재시도 허용 (최대 2회)

## Analysis Plan

| Measure | N=5 test | Notes |
|---------|----------|-------|
| NASA-TLX Video vs Sketch | Wilcoxon signed-rank | 효과크기 r = Z/√5 보고 |
| per-subscale TLX | 기술통계 (median, range) | N=5는 유의검정 어려움 |
| Likert A1–B5 | Median + range | 방향성 해석 |
| Match rating per task | Per-task median | 어떤 task가 어려운지 |
| SUS | 점수 계산 후 mean | 68 이상 = acceptable usability |
| C4 checkbox | 빈도 집계 | 어떤 use case 선호 |
| 주관식 | Thematic analysis (2 themes/participant 목표) | |

**Paper framing for N=5**:
> "We conducted a formative user study (N=5) to evaluate authoring expressiveness and cognitive load. Given the small sample, we report effect sizes and medians rather than significance tests, and treat results as indicative rather than confirmatory."

## 오버레이 비디오 활용 (study 중)

Sketch 결과에서 오버레이 비디오를 켜면 참여자가 자신이 그린 궤적이 Top/Side view로 시각화된 것을 확인할 수 있습니다. 이는:

1. **직관 검증**: "내가 그린 게 실제로 이 방향으로 됐는가" 즉각 확인
2. **디브리핑**: 세션 후 궤적 재생하며 의도와 결과 비교 토론
3. **논문 figure**: 대표 궤적 스크린샷을 캡처해 Figure B로 사용
