IEEE ISMAR 2026 · Poster

Draw one box. Hear it move.

Vid2Spatial turns spatial audio authoring into parameter extraction: a single bounding box on a video, or a freehand stroke on a 3D sphere, becomes a per-frame stream of azimuth, elevation and relative distance. That stream is an editable artifact, replayed by binaural, Ambisonics and OSC consumers. Everything below runs in your browser.

02 · Sketch mode

Sources the camera never saw

Off-screen and non-literal sources are drawn by hand. Drag on the sphere to author a stroke; scroll or pinch to change distance. The stroke keeps its own timing, so playback follows the speed of your hand. This is the same raycaster convention the desktop tool uses: azimuth 0° is straight ahead, positive to the right.

03 · OSC · runtime

The same stream, into any engine

Nothing is re-extracted for a new consumer. The stream is sent over UDP as plain OSC messages; verified receivers include Reaper, Max/MSP, TouchDesigner, Unreal Engine and Pure Data. The terminal mirrors whatever is playing above.

Message layout

/vid2spatial/azimuth     f  az_deg      # +right
/vid2spatial/elevation   f  el_deg      # +up
/vid2spatial/distance    f  d_rel       # 0..1
/vid2spatial/distance_m  f  dist_m
/vid2spatial/velocity    f  deg_per_s
/vid2spatial/timecode    f  seconds
/vid2spatial/frame       i  index
/vid2spatial/spatial     ffff az el d_rel conf   # atomic bundle

05 · Run it yourself

From a video file to a parameter stream

The extraction step needs a GPU and SAM2. Rendering and OSC do not. The local web tool bundles video mode, sketch mode and OSC in one page served by Python.

Install

git clone https://github.com/paiiek/vid2spatial_v2
cd vid2spatial_v2
pip install torch torchvision torchaudio
pip install opencv-python numpy scipy h5py
pip install git+https://github.com/facebookresearch/segment-anything-2.git
pip install ultralytics python-osc   # YOLO-World init, OSC

# local web tool: video + sketch + OSC
cd test/demo && python server.py --port 8090

Python API

from vid2spatial_pkg.v2_spatial_tracker import V2SpatialTracker
from vid2spatial_pkg.foa_render import direct_binaural_sofa
from vid2spatial_pkg.osc_sender import OSCSpatialSender

tracker = V2SpatialTracker(video_path="input.mp4",
                           bbox_init=[x, y, w, h],   # drawn once
                           tracker_type="yw_sam2")
traj = tracker.run()                  # per-frame az, el, d_rel
traj.save("traj.json")

binaural = direct_binaural_sofa(audio_mono, sr=48000,
                                az_rad=traj.az, el_rad=traj.el,
                                sofa_path="kemar.sofa")

OSCSpatialSender("127.0.0.1", 9000).stream_trajectory(traj.frames, fps=30)

Coordinate convention: pipeline azimuth is atan2(x, z), right of image positive; the FOA encoder flips sign to the SOFA / AmbiX convention. Channel order is ACN [W, Y, Z, X]; the default normalisation is ACN/N3D scaled by 1/√2, not SN3D (docs/ISSUES.md I12). KEMAR SOFA file is downloaded separately.
